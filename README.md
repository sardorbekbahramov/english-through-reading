# English Through Reading — Vocabulary Master

Hech qanday API yoki AI kerak emas. Hammasi database dan keladi.

## Funksiyalar
- 30 ta inglizcha passaj (Intermediate → Advanced)
- Har bir passajning O'zbek va Rus tiliga tarjimasi
- Vocabularyda ostida chiziq — bosing → ta'rif va tarjima
- 🔊 Audio talaffuz (Web Speech API)
- ⭐ So'z saqlash (localStorage)
- 🃏 Flashcards (flip kartalar)
- 🧠 Quiz (4 variantli test)
- 📤 So'zlarni export qilish

## Deploy (3 qadam)

### 1. GitHub
```bash
git init
git add .
git commit -m "English Through Reading app"
git branch -M main
git remote add origin https://github.com/USERNAME/english-through-reading.git
git push -u origin main
```

### 2. Vercel
- https://vercel.com ga kiring
- "New Project" → GitHub reponi tanlang
- "Deploy" bosing

### 3. Tayyor!
Hech qanday API key, hech qanday env var kerak emas.

## Local ishlatish
```bash
npm install
npm run dev
# http://localhost:3000
```
